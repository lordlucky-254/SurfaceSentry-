# 🛡️ Ethical Hacking Portfolio

> Write-ups, methodology, cheatsheets and reporting templates from my journey in offensive security, built to help defenders and learn in the open.

## ⚖️ Ethics first

Everything here comes from **legal, authorized** environments only: CTFs, intentionally vulnerable labs, my own home lab, and programs where I had written permission. See [ETHICS.md](ETHICS.md) for my rules of engagement.
